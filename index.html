Heating logger

Heating logger is a personal, non-commercial tool. It records readings from its owner's own Google Nest thermostat (room temperature, humidity, target temperature and whether the heating is on) so the owner can compare radiator-balancing tests at home.

It is used only by its owner and is not offered to anyone else. It only reads data: it never changes any thermostat setting.
