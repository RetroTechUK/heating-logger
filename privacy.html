Privacy policy

Heating logger · last updated 27 October 2026

Who uses it

Heating logger is a personal tool run by its owner (GitHub user RetroTechUK) for their own home. The owner is its only user.

What data it accesses

With the owner's permission, through Google's Smart Device Management API (scope https://www.googleapis.com/auth/sdm.service), it reads the owner's Nest thermostat: room temperature and humidity, target temperature, thermostat mode, eco mode, heating status, connection status, and the device's name and ID. It does not access any other Google account data.

How the data is used

The readings are stored on a private computer in the owner's home and used only to analyse how the home's heating performs. They are not sold, shared with or transferred to anyone, used for advertising, or used to train AI models. The tool never sends commands to the thermostat.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The owner keeps the readings for as long as they are useful and can delete them at any time. Access can be withdrawn at any time from the Google account's third-party access page or in the Google Home app.
